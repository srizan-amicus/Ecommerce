# React Ecommerce Product Cards

A simple React + TypeScript ecommerce product interface built using Vite.

## Features

- Reusable `ProductCard` component
- TypeScript interfaces for product data
- Static product data rendered using `.map()`
- Product image, name, SKU, rating and quantity
- Add to Cart button
- Shopping List button
- Responsive product layout
- Desktop, tablet and mobile support

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Project Structure
